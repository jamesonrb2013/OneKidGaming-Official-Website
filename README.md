# OneKidGaming Official Website

A responsive, dark graphite and electric-blue landing page for OneKidGaming.

## Files

- `index.html` — page structure and content
- `styles.css` — visual system and responsive layouts
- `script.js` — mobile navigation, footer year, and reduced-motion-aware reveal effects
- `assets/favicon.svg` — site favicon
- `Dockerfile` and `nginx.conf` — static Nginx container configured for port 8080

## Local preview

You can open `index.html` directly in a browser. For a closer production-style preview, run any static file server from the repository root.

## Blitz Cloud deployment (not yet deployed)

The Dockerfile is ready for a Docker-based web service. Expected service settings:

- **Runtime:** Docker
- **Port:** 8080
- **Domain target:** `onekidgaming.blitz.cloud` (configure only after confirming domain ownership and DNS settings)

Deployment and DNS changes must be reviewed and explicitly approved before going live.
