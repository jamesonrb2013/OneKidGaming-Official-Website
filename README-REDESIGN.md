# OKG Website 2.0

Static-first public website redesign for OneKidGaming.

Preview locally with `python -m http.server 8000` from the repository root.

GitHub Pages hosts the public HTML/CSS/JavaScript only. It cannot run the existing Express/MySQL backend. Existing account, dashboard, and staff portal files are intentionally preserved while a separate backend hosting plan is prepared.

Keep the root CNAME unchanged. Do not change DNS or email records during this redesign. The contact form opens the visitor's email application and does not submit data to a server. Product status labels must only be updated when availability is confirmed. Review legal pages before enabling analytics, cookies, accounts, or additional data collection.
